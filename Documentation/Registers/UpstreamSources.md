# Upstream sources

Each row names one Rust module, the upstream liboqs path that it translates at the tag in `LIBOQS_VERSION`, the project that liboqs took the code from, and the SHA-256 of the upstream folder. The update procedure uses this table to find the modules that a new liboqs release changes. No module translates upstream code yet, so the table has no rows.
