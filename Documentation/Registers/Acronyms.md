# Acronyms

A name writes each acronym in this table as one unit: all upper case (`MLKEM768`, `userID`) or all lower case at the start of a `lowerCamelCase` name (`kemName`). `cargo xtask check-names` rejects a mixed form such as `MlKem` or `userId`. Add a row when a new acronym enters the code.
