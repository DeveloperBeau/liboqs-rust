# Test vectors

Each row names one file of test vectors that a test reads, the address that `cargo xtask fetch-oracle` downloads it from, and its SHA-256. The files are large, so the repository holds this table and not the files. The command writes each file to `target/oracle/<version>/vectors/` and rejects a file whose SHA-256 differs from the row. The addresses are the addresses that the liboqs tests at the tag in `LIBOQS_VERSION` read, in `tests/test_acvp_vectors.py` and `tests/test_wycheproof_vectors.py`.
